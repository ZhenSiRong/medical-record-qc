# 病案管理系统（MRMS）

> 基于 **Vue 3** 的住院病案管理系统前端演示项目
> 覆盖：**病案归档 · 病案编目 · 病案借阅 · 数据统计 · 病案首页数据上报**

---

## 一、如何运行

### 方式 A：直接打开（最简单，推荐给演示）

双击 `index.html` 即可。项目**不依赖网络、不需要构建、不需要安装任何依赖**，Vue 3 运行时已内置在 `lib/vue.global.prod.js`。

> 建议使用 Chrome / Edge 打开。

### 方式 B：本地静态服务器（体验更接近真实部署）

```bash
# 在项目根目录执行任意一条
python -m http.server 8080
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

## 二、功能模块

系统共 6 大模块，均已在导航中可直接切换体验：

| 模块 | 路由键 | 核心功能 |
| --- | --- | --- |
| 工作台 | `dashboard` | KPI 总览、月度归档趋势、流转状态分布、科室排名、待办中心、操作动态 |
| 病案归档 | `archive` | 病案登记、多条件检索、批量归档、详情查看、CSV 导出 |
| 病案编目 | `catalog` | 待编目队列、ICD-10 疾病编码 / ICD-9-CM-3 手术编码录入、编码库检索、质量分级 |
| 病案借阅 | `borrow` | 借阅申请、审批通过 / 驳回、归还登记、续借、逾期监控与催还预警 |
| 数据统计 | `statistics` | 病案量趋势、疾病谱构成、科室明细、费用与住院日区间分布、质量等级分布 |
| 首页数据上报 | `report` | 上报批次管理、上报前字段完整性校验、执行上报、数据包导出、字段规范说明 |

### 可以实际点击走通的完整业务闭环

```
病案登记(archive) → 归档(archive) → 编目(catalog) → 借阅申请/审批(borrow) → 归还
                                    ↘ 首页数据上报(report)：新建批次 → 校验 → 上报
```

每一次操作都会：
1. 实时反映到 **工作台** 的 KPI、图表与待办数字；
2. 写入 **最近操作动态**；
3. 通过 `localStorage` 持久化，刷新页面不丢失。

## 四、技术要点

- **框架**：Vue 3（Composition API，`setup()` + `ref` / `computed` / `reactive` / `watch`）
- **零依赖**：不引入 Element Plus / ECharts / Axios 等任何第三方库，图表用 SVG 手写
- **状态管理**：`Vue.reactive` 实现轻量集中式 store，替代 Pinia（演示场景无需重量级方案）
- **数据持久化**：`localStorage`，键名 `mrms_state_v1`
- **响应式**：CSS Grid + 媒体查询，适配 1440 / 1024 / 768 三档
- **可访问性**：语义化标签、表格 `<th>` 表头、按钮原生元素

## 五、演示数据说明

系统内置 **近 6 个月、约 108 份** 住院病案模拟数据，覆盖 10 个临床科室、24 条 ICD-10 疾病编码、11 条 ICD-9-CM-3 手术编码。

- 数据由**固定随机种子**生成，每次环境初始化结果一致，便于演示复现；
- 数据分布符合业务规律：离当前越近的月份「未归档」比例越高；妊娠分娩类诊断自动归属妇产科；儿科病案年龄约束在 1–12 岁；
- **故意保留了少量数据缺陷**（约 4% 病案住院费用未结算、约 6% 病案手术操作编码未填），用于演示「上报前数据校验」功能——在首页数据上报模块可以看到校验不通过的问题清单；
- 顶栏「重置数据」按钮可恢复到初始状态；
- 演示账号：**王主任 · 病案室主管 · 病案统计科**（写在 `store.js` 的 `state.currentUser`）。
