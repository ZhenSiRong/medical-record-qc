### 1.2 人员规模与配置标准（[一手] 期刊调查数据）

- **病案人员 : 开放床位** ≈ **1 : 90 ～ 1 : 111.4**（多地调查）；潍坊市 1 : 111.4。
- **编码员 : 开放床位** ≈ **1 : 100**，专业编码员可达 **1 : 400**；国外发达国家约 **1 : 10–20**（**缺口约数十倍**）。
- 潍坊市编码员**日均负担出院病案 44 份**；吉林 96 家二级以上医院**平均每家仅 1.93 名编码员、日均编码 55.9 份**；河南省**34.54% 的医院编码员月均负担 ≥100 份**。
- 国际 meta 分析（BMC Med Inform Decis Mak，2024）[二手]：每位编码员**年均约 11,300 份**，三甲可达 **12,049 份/年**，个别地区（太原三甲）人均 **32,100 份/年**——折算约**每 10 分钟需处理 1 份**住院病案。

### 1.3 编制归属与等级医院差异（[一手] 期刊调查）

| 维度 | 三级医院 | 二级 / 基层医院 |
|---|---|---|
| 独立性 | 部分独立设科（潍坊仅 **41.7%** 独立） | **普遍未独立设科**（张掖 118 家 **全部**未独立；内蒙古 110 所二级医院仅 **20%** 独立） |
| 隶属关系 | 多挂靠医务科 | 约 **50.8%** 隶属医务科 / 办公室 / 信息科 / 医保科 |
| 负责人 | 多为专职 | 张掖 **96.6% 负责人为兼职** |
| 人员缺口 | 约 **81.48%** 医院存在人员缺口 | 南充配比 0.4 : 50，**远低于 1 : 50 标准**；编码员常**兼职其他病案工作（一岗多职）** |

### 1.4 人员专业背景（[一手] 期刊调查）

- 湖北 2018 调查：**转岗的医学相关人员近 60%**，对口的**卫生信息统计管理专业仅 20%**，**22% 无任何医学背景**。
- 全国 meta：**39% 编码员缺乏医学背景**，仅 **61% 持编码证**，**51% 工作经验不足 5 年**。
- 湖南 109 家医院 216 位编码员：**初级及以下职称占 40.3%**，持编码培训合格证 **38%**，**年均业务学习仅 0.89 次**。

## 2. 日常工作流时间线（出院 → 归档 → 上报）

### 2.1 单份病案的流转链路

> 一份住院病案从出院到最终归档，行业说法**平均经手约 6 次**：护士整理 → 医生写病程/首页 → 主治审核 → 质控抽查 → 病案科编码 → 终末质控。**任一环节停顿即造成延迟**（[二手]《中国病案》相关研究综述）。

```
患者出院
  │  ① 临床：补全病程、填写病案首页、科内自查
  │  ② 护士整理 / 主治医师审核签字
  ▼
【回收】护士/医生送至病案科 或 病案科上门回收              目标：出院后 2～7 个工作日内
  ▼
【整理装订】核对页数、装订成册
  ▼
【编码】编码员赋 ICD-10 / ICD-9-CM-3，交叉审核             ← 核心瓶颈，日均 44～56 份/人
  ▼
【首页质控 / 终末质控】三类规则校验（必填/逻辑/编码存在性）
  │    └─ 有缺陷 → 退回临床科室返修（线上申诉 / 复议 / 二次复核）→ 回到质控
  ▼
【归档上架】绑定库位、密集架、形成病案示踪时间轴
  ▼
【借阅 / 复印 / 封存】 借阅须审批，原件一般不出病案科
  ▼
【上报】HQMS 首页数据 + 卫生统计月报 + 医保结算清单 + 绩效考核
```

### 2.2 例行工作节奏与时限要求

| 周期 | 工作事项 | 时限 / 目标 | 依据性质 |
|---|---|---|---|
| 每日 | 病案回收、编码、催促临床返修；HQMS 首页数据上传 | HQMS 前置机**每天定时自动上传** | [二手] 采购技术文件 |
| 出院后 | 病案归档 | **2 个工作日 ≥95%（A）/ 3 个工作日 ≥90%（B）/ 7 个工作日 ≥90%（C）**（江苏省三级标准）；国家要求**归档及时率 ≥90%** | [一手] 地方标准 |
| 每月 | 住院病案首页个案月报（卫健统 4-1 / 4-2 / 4-3） | **次月 25 日前**网络直报（禅城要求**20 日前报、25 日前审核订正**） | [一手] 卫生统计调查制度 |
| 每月 | 医疗服务月报（卫健统 1-8） | **次月 20 日前**直报（禅城：10 日报、15 日审、20 日标注；江西要求 15 日前） | [一手] 卫生统计调查制度 |
| 每月 | 数据订正 | 上报后**2 日内**订正；截止前 3 日系统催报 | [一手] 统计制度 |
| 每月 | 数据一致性 | **首页个案与月报出院人次一致率 ≥98%** | [一手] 统计制度 |
| 每月 | DRG/DIP 月度结算、科室绩效核算 | 月末关账（具体日期按院） | [推测] 行业惯例 |
| 每季 | 首页质控抽查、编码正确率自查上报 | 季度改进指标 | [二手] 质控目标文件 |
| 每年 | 医疗卫生机构年报（卫健统 1-1） | **次年 1 月 20 日前** | [一手] 统计制度 |
| 每年 | 三级公立医院绩效考核（"国考"）数据上报 | 按国家年度安排 | [二手] 绩效考核文件 |

### 2.3 病案科在「国考」与 DRG 中的位置（[二手] 政策/媒体综述）

- 三级公立医院绩效考核 55 个指标中，**7 个直接取自病案首页**（占医疗质量指标 29.2%），涉及分值约 **345 分 / 1000 分**；26 个国家监测指标中 **9 个**与首页相关。
- 医保结算清单 **190 个数据项中 66 项来自病案首页**。
- 行业口号：**"得病案首页者得天下""DRG 付费时代，编码就是钱（coding = money）"**。
- 国家目标：首页填写规范率 **≥98%**、编码准确率 **≥99%**；《全面提升医疗质量行动计划（2023—2025 年）》要求**2025 年末主要诊断编码正确率 ≥90%**、病历归档完整率 ≥98%（实景：2022 年 8116 家医院自查已达 90.09%）。

## 4. 与临床的关系与权力

### 4.1 病案科能对临床医生施加的约束（"管医生的医生"）

| 权力 / 抓手 | 作用机制 | 依据性质 |
|---|---|---|
| **首页质控扣分** | 首页完整率、规范率纳入**科室绩效目标考核，与责任医生奖金挂钩** | [一手] 学术论文 |
| **编码影响 DRG/DIP 入组** | 少写并发症/漏填手术 → 落入低权重病组 → **科室少收钱**（如心衰只写"心功能 III 级"漏病因诊断，入组权重降 30%–50%） | [二手] 媒体 / 综述 |
| **病历书写规范约束** | 终末质控发现问题**退回临床返修**，可线上申诉、复议、二次复核 | [二手] 采购技术文件 |
| **借阅审批权** | 借阅须申请审批、限期归还（行业惯例及院规多要求**3 个工作日内归还**）；原件一般**不出病案科** | [一手] 顺承《医疗机构病历管理规定》精神 |
| **归档时限考核** | 归还/归档超期可**连带科主任、护士长**责任 | [一手] 科室责任制研究 |
| **上报数据把关** | 上报前质控不通过则不予上报（数据源头在临床） | [推测] 流程推断 |

### 4.2 典型矛盾点

1. **两套评价体系对撞**：临床 KPI 是**诊疗效率与质量**（"把病人处理好"）；病案科 KPI 是**数据质量与编码准确**。DRG 后首页成为结算唯一凭证，冲突激化——临床嫌病案科"挑刺"，病案科嫌临床"写得太糙"。（[二手] 媒体《临床与病案科的矛盾》）
2. **"第一责任人"错位**：规范明确**临床医师为病案首页填写第一责任人**，编码员**不能凭空添加/修改诊断**；于是编码员发现问题只能退回，遇医生不改则无解。（[二手] 行业综述）
3. **绩效连带引发的对抗**：临床"手术做得多，首页没填好，相当于白干"；编码错误导致的拒付最终**记在全院/质控科头上**，形成"互相甩锅"。（[二手] 凤凰网《填错一次病案首页，让我的科室亏了 1 个月》）
4. **口令人知**：医生吐槽"我一天做 5 台手术，还要花 2 小时跟病案室吵架"。（[二手] 媒体）
5. **合规红线争议**：**病案科**按 ICD 技术标准判"编码误差"，**医保科**按基金支付综合判定，可能将同一件事认定为"高套编码/虚假结算"——两套口径是**主要风险来源**。（[二手] 综述）
6. **科室间公平性**：外科病种易见结余、内科慢病/危重症易超支，编码规则与权重差异被临床归因于病案科。（[二手] DRG 绩效综述）

### 对现有系统的不满（[一手/二手] 无纸化与信息化研究）

- **多系统不协同**："系统不协同，报告难控制"；各业务系统流程与文件格式各异、接口难对接。
- **"假无纸化"**：只做了最后一步扫描翻拍，前面仍是纸质流转，完整性难以质控。
- **单机设备对接难**：大量传统设备不联网、数据格式私有，需额外解耦转换。
- **流程再造与权限**：病案模板难适配、多院区协同难、电子签名认识误区、信息安全与隐私顾虑。

## 附：给「匹配度分析」的三句话提示

1. **编码环节是病案科的"产能瓶颈 + 经济命脉"**，系统最高价值在**智能预编码 + 编码正确率/DRG 预分组预警**（对应本系统"编目""首页质控""上报"三功能域）。
2. **"退回-返修闭环"是与临床的主要摩擦面**，系统须把"退回理由可追溯、医生可申诉/复议、二次复核留痕"做扎实，否则复制线下对骂（对应"首页质控 + 操作日志审计"）。
3. **"示踪 + 催缴 + 借阅审批归还"是病案科最基础的日常刚需**（对应"归档 + 借阅 + 统计"），也是"零丢失、可审计"的合规底线。
